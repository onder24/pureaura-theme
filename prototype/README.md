# PureAura – Prototyp

Statischer Entwurf der neuen Seite (HTML/CSS/JS, ohne Shopify). Wird später in ein
Shopify-Theme umgewandelt; jeder Abschnitt ist dafür als eigener Block aufgebaut.

## Lokal ansehen

    npx serve prototype

## Vercel

- Root Directory: `prototype`
- Framework Preset: Other
- Build Command: leer
- Production Branch: `prototype`

`vercel.json` setzt `noindex`, damit der Entwurf nicht bei Google landet.
