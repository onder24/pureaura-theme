# PureAura – Prototyp

Statischer Entwurf der neuen Seite (HTML/CSS/JS, ohne Shopify). Wird später in ein
Shopify-Theme umgewandelt; jeder Abschnitt ist dafür als eigener Block aufgebaut.

## Lokal ansehen

    npx serve prototype

## Cloudflare Pages

- Production branch: `prototype`
- Framework preset: None
- Build command: leer
- Build output directory: `prototype`

`_headers` setzt `noindex`, damit der Entwurf nicht bei Google landet.
